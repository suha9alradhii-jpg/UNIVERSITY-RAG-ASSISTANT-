# 🎓 University RAG Assistant

A local Retrieval-Augmented Generation (RAG) system built with Streamlit, ChromaDB, and OpenRouter integration to answer academic and university-related queries accurately based on custom document uploads.

---

## 🚀 Features
- **Document Processing & Chunking:** Upload and index text documents dynamically.
- **Vector Search:** Powered by ChromaDB and local sentence-transformers (`all-MiniLM-L6-v2`) for precise semantic retrieval.
- **Smart Generation:** Generates concise and accurate responses using OpenRouter API (`gpt-4o-mini`).
- **User Interface:** Clean and interactive web interface built with Streamlit.

---

## 🛠️ Tech Stack
- **Python** (3.13+)
- **Streamlit** (UI framework)
- **ChromaDB** (Vector Database)
- **Sentence-Transformers** (Local Embeddings)
- **OpenAI / OpenRouter API** (LLM Response Generation)
